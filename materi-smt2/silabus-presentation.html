FASE 1 (Sesi 1-6)

Fondasi "Cloud", "Save Game", & Python 💻

Fokus: Paham konsep server cloud, kebiasaan simpan kode ke GitHub, dan menguasai dasar bahasa Python.

Sesi 01 Cloud Setup

Perkenalan GitHub & Codespaces

Membuat repository, meluncurkan cloud IDE, jalankan file main.py & ASCII art.

Sesi 02 Git & Variable

Ritual "Sync" & Kotak Data

Menyimpan kode via UI Source Control (Commit & Sync) & menyimpan data dalam Variabel.

Sesi 03 Math & Logic

Kalkulator Server

Memahami tipe data Integer, Float, String, dan operasi aritmatika (+, -, *, /).

Sesi 04 Interactive

Ngobrol Sama Komputer

Menggunakan fungsi input() dan f-string untuk menerima jawaban pengguna secara dinamis.

Sesi 05 Decision

Logika Bercabang (If-Else)

Membuat keputusan otomatis dengan struktur kondisi if, elif, dan else.

Sesi 06 Evaluation

Review & Mini Project Python

Menggabungkan variabel, input, dan if-else untuk game "Pilih Jalan Cerita".

FASE 2 (Sesi 7-12)

Membangkitkan Bot & Telegram Runtime 🤖

Fokus: Mengkoneksikan Python ke API Telegram, paham konsep polling, & penanganan media.

Sesi 07 Telegram Setup

Lahirnya Sang Bot

Membuat Bot di BotFather, amankan Token, & install pyTelegramBotAPI.

Sesi 08 Polling Concept

Konsep Runtime & Bot Beo

Paham kenapa bot standby 24/7 (polling) dan membuat echo-bot pertama.

Sesi 09 Commands

Bot Patuh Perintah

Decorator @bot.message_handler untuk respon /start, /help, dan /sosmed.

Sesi 10 Text Filtering

Bot Paham Teks & Anti-Toxic

Membaca obrolan teks biasa dan memberi filter pintar untuk mendeteksi kata terlarang.

Sesi 11 Media Handling

Bot Ngirim Gambar & Stiker

Mengirim foto dari URL internet via /foto dan mengirim stiker Telegram favorit.

Sesi 12 Evaluation

Mini Project Bot Asisten

Menggabungkan Sesi 7-11 menjadi satu Bot Asisten Pribadi yang responsif.

FASE 3 (Sesi 13-18)

Struktur Data & Alur Percakapan 📚

Fokus: Mengolah data majemuk (List & Dictionary) dan membuat percakapan bertahap.

Sesi 13 Data Structure

Rak Buku Server (List)

Menyimpan kumpulan data dalam List, serta memanipulasinya (append, remove).

Sesi 14 Iteration

Mesin Pengulang (For Loop)

Melakukan perulangan otomatis untuk membaca seluruh isi List secara efisien.

Sesi 15 Bot Integration

Daftar Menu Telegram

Menggabungkan List & Loop ke dalam command /menu bot dengan emoji bullet point.

Sesi 16 Key-Value

Loker Laci Ganda (Dictionary)

Konsep Key-Value di Dictionary sebagai fondasi menyimpan skor dan data user.

Sesi 17 Dialog Flow

Percakapan Berantai (Part 1)

Percakapan Berantai (Part 2)

FASE 4 (Sesi 19-24)

Proyek Akhir: Bot Kuis Interaktif 🏆

Fokus: User state memory, Reply Keyboards, validasi jawaban, & Demo Day.

Sesi 19 State & Memory

Memori Bot & Skor User

Menyimpan skor per-User ID Telegram dengan Dictionary agar data tidak tertukar.

Sesi 20 Quiz Engine

Merancang Pertanyaan Kuis

Validasi Jawaban Kuis

Demo Day & Perayaan! 🎉

Presentasi hasil karya, saling mencoba bot buatan teman, & selebrasi kelulusan.
